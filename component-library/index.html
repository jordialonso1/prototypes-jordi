Component library

The Pintxo components in shared-design-system/pintxo/ that prototypes can reuse. They are plain CSS: link pintxo.css from an HTML prototype. When you add a component to the shared folder, add its examples here too.

Button

pintxo.css

Pintxo pill button. Neutral by default, --primary for the main action. Sizes --s 40px, --m 48px, --l 64px. Add --trailing-icon when an icon follows the label, --block for full width. The disabled attribute greys it.

File: shared-design-system/pintxo/pintxo.css

Icon button

pintxo.css

Round icon-only button. 40px with a 24px icon by default, --s is 32px with a 16px icon. --floating is the white version with a border, used over images. Always set an aria-label.

File: shared-design-system/pintxo/pintxo.css

Counter

pintxo.css

Quantity stepper. xs (32px) by default, --l is the 48px one. A disabled button greys its icon. --collapsed shows only the trailing "+" for a product that is not in the cart yet; swap it for the full counter after the first add. For the floating "+" on a product tile use a small floating icon button instead.

File: shared-design-system/pintxo/pintxo.css

Banner

pintxo.css

Message banner. Set the style with data-style: neutral, positive, critical, warning, marketing, loyalty. Combine with an icon blob for warnings and errors.

File: shared-design-system/pintxo/pintxo.css

Icon blob

pintxo.css

24px blob with an exclamation triangle. Styles: warning, critical. Meant to sit at the start of a banner.

File: shared-design-system/pintxo/pintxo.css

Radio button

pintxo.css

24px radio. Restyles the native input, so it stays focusable. Keep data-checked, data-error and data-disabled in sync with the input in JS. data-align="right" on the label puts the control after the text.

File: shared-design-system/pintxo/pintxo.css

Checkbox

pintxo.css

24px checkbox. Same approach as the radio button: keep data-state (checked, unchecked, indeterminate), data-error and data-disabled in sync with the input.

File: shared-design-system/pintxo/pintxo.css

Tag

pintxo.css

Small label. Set data-style (neutral, positive, critical, warning, contrast) and data-variant (primary solid, secondary tinted). Add the caption-emphasis typography class. A leading 16px <svg> or <img> icon is optional.

File: shared-design-system/pintxo/pintxo.css

Section header

pintxo.css

Title (21/24 bold) with an optional description and an optional trailing slot for a tag, icon button or link. data-state="error" on the header turns the description red.

File: shared-design-system/pintxo/pintxo.css

Status bar

pintxo.css

iOS status bar for the top of a prototype screen: 62px tall, time on the left, signal icons on the right, room for the notch in between. The icons are in shared-design-system/pintxo/assets/; adjust the src path to the prototype's depth. Position it yourself, for example inside a fixed nav.

File: shared-design-system/pintxo/pintxo.css
